## 一、数据概况

- 接诉即办共 30,421 条；`主要内容` 非空 30,419 条（99.99%）。
- 收件时间覆盖 2024-08-30 至 2026-01-07。
- 现有一级分类仅 2 条为空；二级分类 24,061 条为空（79.1%）。非空值按原始字段计，一级分类有 719 个不同文本值，二级分类有 124 个不同文本值；一级字段中含有层级路径等不同粒度表达。因此现有分类可作主题发现和核对的参考，但不宜不经清洗直接当作统一枚举。
- 现有 `工单类型` 几乎齐全，主要值为：诉求 22,861、建议 3,697、咨询 2,751、投诉 978、表扬 99。它表达的是办理意图/来件类型，建议与“诉求主题”分开。

## 四、建议的主题树（初版）

建议配置字段标题用 **“诉求主题分类”**，做成“一级主题 → 二级主题”的可维护分类树；模型负责匹配，不自由发明枚举值。先用“其他/未识别/待人工复核”承接边界不清的记录。

1. **轨道交通与公共交通**
   - 轨道线路规划、调整与延伸
   - 轨道站点增设、选址、迁移与出入口
   - 轨道交通服务、运营和设施
   - 公交线路、站点与接驳
2. **城乡规划与规划意见**
   - 控规/空间规划调整与公示
   - 规划方案意见、反对或异议
   - 规划审批、许可与办理
   - 交通规划与市政道路规划
3. **建设施工与工程影响**
   - 施工噪声、扬尘、振动、夜间施工
   - 施工占道、出行影响与工程协调
   - 工程质量、施工安全及周边受损
4. **违法建设与执法处置**
   - 违法建设/违章搭建
   - 违法用地或违规改变用途
   - 举报、查处与执法进度
5. **征收拆迁与城市更新**
   - 征地、房屋征收与腾退
   - 补偿安置、评估与历史遗留问题
   - 老旧小区改造及更新配套
6. **住房与小区治理**
   - 房屋质量、老旧房屋与安全隐患
   - 不动产登记、房屋权属与产权证
   - 物业服务、小区设施与公共空间
7. **自然资源、土地与地理信息**
   - 土地权属、宅基地与确权登记
   - 土地利用、供地与用地性质
   - 测绘、地名、门牌地址与空间边界
8. **审批咨询与政务服务**
   - 政策法规及办事流程咨询
   - 审批时限、办理进度与部门协同
   - 服务态度、履职和投诉建议
9. **生态环境与绿化保护**
   - 绿地、树木及生态空间
   - 环境影响及其他空间保护事项
10. **企业与行业服务**
    - 企业资质、行业许可与工程咨询
    - 企业办事、项目审批及政策服务
11. **其他/复合主题**
    - 无法归入已配置主题
    - 一条工单包含多个独立主题（标记复合主题并转复核）

## 五、建议拆分的字段与规则

- `诉求主题分类`：层级枚举，分别保存一级、二级编码；可多主题，但必须标出主主题。
- `主题摘要`：简短自由文本，例如“建议在北部片区增设轨道站点”；它与枚举分类分开。
- `诉求意图`：沿用现有工单类型（诉求、建议、咨询、投诉、表扬等），不要混入主题树。
- `诉求主体 / 行为 / 目标对象 / 期望结果`：作为主体语义抽取字段，各自保留正文证据。
- `地点名称 / 地点类型`：分别保存地点和地点角色；至少区分“事件发生地”和“诉求目标地点”。新增站点建议的目标位置应落图为“诉求目标地点”。
- `所属小区 / 涉及轨道线路 / 涉及站点`：实体字段，关联后续维护的对象目录；目录未接通前只输出候选名称与证据，并进入待复核。
- `复核原因 / 置信度 / 原文证据`：作为质量控制字段。低置信、主题冲突、多地点或对象唯一性不足时不自动通过。

## 六、建议的落地顺序

1. 以此主题树作为候选草案，不直接发布为正式枚举。
2. 在本地按现有一级分类、渠道、时间分层抽取约 300–500 条样本，覆盖轨道交通、规划施工、住房、土地、咨询等主要类别。
3. 人工检查模型主题匹配、边界和“其他”比例，补充定义、正反例和同义词；特别复核低频主题与复合诉求。
4. 再用独立样本评估一级/二级分类准确率、主题覆盖率、人工复核比例；达到业务阈值后发布版本，最后才批量处理全量历史数据。

## 方法与限制

统计在本地 PostGIS 数据库上完成；关键词命中采用正则短语规则，允许重叠。本文未将整批工单正文发送到 DeepSeek，也未对 30,421 条逐条进行模型分类。现有分类是历史字段，存在二级分类缺失和口径不一致，因此推荐主题树是供抽样验证的初版，而非已确认的最终分类标准。
